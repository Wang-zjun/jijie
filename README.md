# 解集 · Solution Set Site

校内数竞生论坛（当前为本地演示版，后续接云端实现真互通）。

**线上地址（GitHub Pages）**：https://wang-zjun.github.io/jijie/

## 运行
```bash
cd jijie
python -m http.server 8734 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8734/welcome.html
```

## 账号
- **管理员**：`admin` / `admin123`（积分无限，可审批题目/题解、给用户加积分、删帖置顶发通知）
- 普通用户：在欢迎页注册即可（初始 20 积分）

## 积分制度
- 初始 **20 积分**
- **每日签到**：抽签同时给积分（大吉10/小吉8/中平5/小凶2/大凶1，一天一签）
- **做题**：难度 × 5 积分，提交解答后**管理员审核**通过才发放
- **悬赏**：发布时从悬赏者账户扣积分，解题者答对后获得
- **管理员**：积分无限，可给任意用户加积分
- **上传题目**：普通用户可上传，**必须带题解**（没题解提示发布到悬赏板），需管理员审核后公开

## 功能
- 主题自选（4 套）+ localStorage 记住 + 随时切换
- 每日一言（本地台词库，二次元+数学，按日期每天稳定）
- 随机跳题
- 每日打卡抽签（大吉/小吉/中平/小凶/大凶，一天一签）
- 讨论板 / 资源库 / 文章专栏 / 题库 / 悬赏板
- 搜索用户、加好友、邮件
- 个人主页（简介可编辑、上传头像、最近做题）
- 管理员面板（用户/题目/帖子/悬赏/资源/文章/通知 全面管理）
- **KaTeX 数学公式**：帖子/文章/题目/评论里用 `$...$`（行内）或 `$$...$$`（块级）写 LaTeX 公式，自动渲染（本地库，离线可用）

## 数学公式写法
```
行内：$a^2 + b^2 = c^2$   →  a²+b²=c²
块级：$$\int_0^1 x^2\,dx = \frac{1}{3}$$
```
KaTeX 本地文件在 `js/vendor/katex/`，无需联网。
